## 2. 읽을 때 알아 둘 것

1. 모두 AI가 쓴 글입니다. 아래 3번의 가린 곳 말고는 고치지 않았습니다.
2. "팀원"은 역할 이름이고 실제 팀원(lgosoup)이 아닙니다. 토론한 11/19에는 실제 팀원이 아직 저장소에 들어오기 전이었습니다.
3. 공개 저장소라 다른 저장소 이름과 커밋 수, 계정의 noreply 주소, PC 경로를 가렸습니다. 개인 메일 주소는 원문에도 없습니다.
4. 파일 이름을 영어로 바꾸면서 원문 안에 적힌 파일 이름도 같이 바꿨습니다.
5. 올리지 않은 것
   - 1라운드 지시문: 에이전트를 실행할 때 바로 넣어 따로 저장하지 않았습니다. 2라운드 지시문에 1라운드 쟁점이 정리되어 있습니다.
   - 검토 자료와 GPT에게 보낸 프롬프트, 실행 기록: 저장소 상태와 개인 정보가 섞여 있고, 검토 자료 전체가 프롬프트에 다시 들어 있어 양이 많습니다.
6. 원문의 PR 번호와 문서 이름은 11/19 당시 것입니다. 그 뒤 문서 번호가 바뀌었습니다. 예를 들어 `05_ai_corrections.md`는 지금 `docs/ideation/03_ai_corrections.md`이고, `06_pretest.md`는 `04_pretest.md`로 쓰기로 했습니다.
